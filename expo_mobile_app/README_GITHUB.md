# Mercurio Expo Mobile App

This folder contains the Expo React Native implementation generated from the MercurioAndroid2026 concept. It is intentionally stored in `expo_mobile_app/` so the existing Flutter project remains intact.

## Run locally

```bash
cd expo_mobile_app
pnpm install
pnpm check
pnpm test
pnpm dev
```

The current Expo app is a local prototype. It supports generated local identity onboarding, local contacts, local chat preview, QR-style ID sharing, settings, and AsyncStorage persistence. It does not yet provide real two-device message delivery.
